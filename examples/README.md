# Examples

Examples connect the capability-fit framework to application domains.

Available now:

- [Offline agent intake](agent-intake/README.md): a complete description-only JSON
  brief that requires no browser, credential or model call.
- [MCP quickstart](quickstart/README.md): orientation calls for the existing L2
  interface, with runtime credentials.

Planned examples:

- financial markets
- patient monitoring
- fusion diagnostics
- industrial systems
- cybersecurity
- autonomous systems

Examples are explanatory. Benchmarks are reproducible evaluations. Keep the distinction clear.
